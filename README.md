# 💍 YesNoProposal

A modern and interactive proposal website designed to create a memorable "Yes or No" experience. Built with HTML, CSS, and JavaScript, the project features smooth animations, responsive design, and an engaging user interface.

## ✨ Features

- ❤️ Interactive Yes/No proposal interface
- 🎨 Beautiful and responsive UI
- ⚡ Smooth animations and transitions
- 📱 Mobile-friendly design
- 🌐 Fast and lightweight static website
- 🚀 Easy deployment with GitHub Pages or Cloudflare Pages

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 📦 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/kathirvelan-dev/YesNoProposal.git
   ```

2. Open the project folder:
   ```bash
   cd YesNoProposal
   ```

3. Open `index.html` in your browser.
